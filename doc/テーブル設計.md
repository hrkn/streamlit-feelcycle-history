# テーブル設計

本ドキュメントは、Feelcycleの受講履歴をAPI経由で取得し、ローカルのSQLite3データベースに格納するためのテーブル設計仕様書です。
ORMとしてSQLAlchemy (2.0スタイル) を使用することを想定しています。

---

## 1. 基本設計方針

* **データベース**: SQLite3
* **ORM**: SQLAlchemy
* **主キー (PK) 設計**: 
  * 明示的に自然キーが指定されているエンティティを除き、基本的にはオートインクリメントの `id` (INTEGER) をサロゲートキーとしてプライマリキーに設定します。
  * 自然キー (プログラム名など) は `UNIQUE` 制約を設定し、インデックスを付与することで検索効率と一意性を担保します。

---

## 2. テーブル構成一覧

本設計で採用する各テーブルの物理名とクラス名の対応は以下の通りです。

| テーブル名 | クラス名 | 説明 |
| :--- | :--- | :--- |
| `members` | `Member` | 会員個人を管理します。 |
| `web_accounts` | `WebAccount` | 会員に紐づくマイページのアカウント情報を管理します。 (1人の会員が複数アカウント保持可能) |
| `programs` | `Program` | レッスンのプログラム (BB2 Hit11 等) を管理します。 |
| `lessons` | `Lesson` | スケジュールされた各レッスン枠の情報を管理します。 |
| `lesson_histories` | `LessonHistory` | 会員アカウントごとの受講実績 (予約・受講・欠席) を管理します。 |
| `web_account_history_updates` | `WebAccountHistoryUpdate` | Webメンバーアカウントごとの受講履歴更新履歴を管理します。 |

---

## 3. テーブル定義 (物理設計)

### 3.1. 会員 (members)

会員個人を管理するテーブルです。

| カラム名 | 物理名 |データ型 | NULL | キー | 初期値 | 説明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 会員ID | `id` | `INTEGER` | NO | PK | - | オートインクリメントID |
| 氏名 | `name` | `VARCHAR(20)` | NO | - | - | 会員の氏名 |

### 3.2. Webメンバーアカウント (web_accounts)

マイページのログイン情報や識別用アイコンを管理するテーブルです。会員に対して 1:多 で紐づきます。

| カラム名 | 物理名 | データ型 | NULL | キー | 初期値 | 説明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| アカウントID | `id` | `INTEGER` | NO | PK | - | オートインクリメントID |
| メールアドレス | `email` | `VARCHAR(50)` | NO | UNIQUE | - | ログイン用のメールアドレス (インデックス付与) |
| 会員ID | `member_id` | `INTEGER` | NO | FK | - | `members.id` への外部キー (インデックス付与) |
| 識別用アイコン | `icon` | `VARCHAR(8)` | NO | - | - | マイページ識別用の絵文字等 |

### 3.3. プログラム (programs)

レッスンのプログラムを管理するテーブルです。プログラム名は `UNIQUE` とし、サロゲートキー `id` を主キーとします。

| カラム名 | 物理名 | データ型 | NULL | キー | 初期値 | 説明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| プログラムID | `id` | `INTEGER` | NO | PK | - | オートインクリメントID |
| プログラム名 | `name` | `VARCHAR(12)` | NO | UNIQUE | - | プログラム名 (一意、インデックス付与) |
| 背景色 | `background_color`| `VARCHAR(20)` | YES | - | NULL | アプリ上の表示背景色 (HEXコード等) |
| 文字色 | `text_color` | `VARCHAR(20)` | YES | - | NULL | アプリ上の表示文字色 (HEXコード等) |

### 3.4. レッスン (lessons)

スケジュールされた各レッスン枠の情報を管理するテーブルです。

| カラム名 | 物理名 | データ型 | NULL | キー | 初期値 | 説明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| レッスンSID | `sid` | `VARCHAR(160)` | NO | PK | - | Feelcycle APIから取得できるレッスン一意識別子 |
| 店舗ID | `store_id` | `INTEGER` | NO | - | - | 提供店舗のID (インデックス付与) |
| 店舗名 | `store_name` | `VARCHAR(20)` | NO | - | - | 提供店舗の名称 |
| インストラクターID1| `instructor_id_1` | `INTEGER` | NO | - | - | メインインストラクターのID |
| インストラクター名1| `instructor_name_1`| `VARCHAR(20)` | NO | - | - | メインインストラクターの氏名 |
| インストラクターID2| `instructor_id_2` | `INTEGER` | YES | - | NULL | サブインストラクターのID (所属インストラクターが複数名の場合のみ) |
| インストラクター名2| `instructor_name_2`| `VARCHAR(20)` | YES | - | NULL | サブインストラクターの氏名 (所属インストラクターが複数名の場合のみ) |
| 開始日時 | `start_at` | `DATETIME` | NO | - | - | レッスンの開始日時 (インデックス付与) |
| 終了日時 | `end_at` | `DATETIME` | NO | - | - | レッスンの終了日時 |
| プログラムID | `program_id` | `INTEGER` | NO | FK | - | `programs.id` への外部キー (インデックス付与) |
| 更新日時 | `updated_at` | `DATETIME` | NO | - | CURRENT_TIMESTAMP | データの最終更新日時 (D1同期用) |

### 3.5. レッスン受講履歴 (lesson_histories)

会員のWebアカウントごとの受講実績を管理するテーブルです。

| カラム名 | 物理名 | データ型 | NULL | キー | 初期値 | 説明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| 履歴ID | `id` | `INTEGER` | NO | PK | - | オートインクリメントID |
| WebアカウントID| `web_account_id` | `INTEGER` | NO | FK | - | `web_accounts.id` への外部キー (インデックス付与) |
| レッスンSID | `lesson_sid` | `VARCHAR(160)` | NO | FK | - | `lessons.sid` への外部キー (インデックス付与) |
| バイクナンバー | `bike_number` | `VARCHAR(20)` | NO | - | - | 受講した自転車の番号 |
| 利用チケット | `ticket_type` | `VARCHAR(100)` | YES | - | NULL | 受講に使用したチケットや枠の名称 (例: 「マンスリー枠」「有料チケット」) |
| 不参加 | `is_absent` | `BOOLEAN` | NO | - | FALSE | 予約したものの無断欠席等の理由で受講しなかった場合は TRUE |

### 3.6. Webメンバーアカウント受講履歴更新履歴 (web_account_history_updates)

Webメンバーアカウントごとの受講履歴の月別更新履歴を管理するテーブルです。`(web_account_id, year, month)` の3列複合を主キーとします。

| カラム名 | 物理名 | データ型 | NULL | キー | 初期値 | 説明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| WebアカウントID | `web_account_id` | `INTEGER` | NO | PK, FK | - | `web_accounts.id` への外部キー (インデックス付与) |
| 対象年 | `year` | `INTEGER` | NO | PK | - | 受講履歴の対象年 (例: 2024) |
| 対象月 | `month` | `INTEGER` | NO | PK | - | 受講履歴の対象月 (例: 8) |
| 最終更新日時 | `last_updated_time` | `DATETIME` | NO | - | CURRENT_TIMESTAMP | 該当月履歴の最終更新日時 |

## 4. リレーションシップ (ER図)

```mermaid
erDiagram
    members ||--o{ web_accounts : "1:多"
    web_accounts ||--o{ lesson_histories : "1:多"
    web_accounts ||--o{ web_account_history_updates : "1:多"
    lessons ||--o{ lesson_histories : "1:多"
    programs ||--o{ lessons : "1:多"

    members {
        INTEGER id PK
        VARCHAR name
    }

    web_accounts {
        INTEGER id PK
        VARCHAR email UNIQUE
        INTEGER member_id FK
        VARCHAR icon
    }

    programs {
        INTEGER id PK
        VARCHAR name UNIQUE
        VARCHAR background_color
        VARCHAR text_color
    }

    lessons {
        VARCHAR sid PK
        INTEGER store_id
        VARCHAR store_name
        INTEGER instructor_id_1
        VARCHAR instructor_name_1
        INTEGER instructor_id_2
        VARCHAR instructor_name_2
        DATETIME start_at
        DATETIME end_at
        INTEGER program_id FK
        DATETIME updated_at
    }

    lesson_histories {
        INTEGER id PK
        INTEGER web_account_id FK
        VARCHAR lesson_sid FK
        VARCHAR bike_number
        VARCHAR ticket_type
        BOOLEAN is_absent
    }

    web_account_history_updates {
        INTEGER web_account_id PK, FK
        INTEGER year PK
        INTEGER month PK
        DATETIME last_updated_time
    }
```

## 5. SQLAlchemy 2.0 モデル定義例

確定したスキーマで定義した実装サンプルコードです。既存の `src/streamlit_feelcycle/model.py` をリファクタリングする際の参考にしてください。

```python
import datetime
import typing

import sqlalchemy
import sqlalchemy.orm


class Base(sqlalchemy.orm.DeclarativeBase):
    pass


class Member(Base):
    """会員"""

    __tablename__ = "members"

    id: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        primary_key=True, autoincrement=True
    )
    name: sqlalchemy.orm.Mapped[str] = sqlalchemy.orm.mapped_column(
        sqlalchemy.String(20), nullable=False
    )

    # Relationships
    web_accounts: sqlalchemy.orm.Mapped[list["WebAccount"]] = (
        sqlalchemy.orm.relationship(back_populates="member")
    )


class WebAccount(Base):
    """Webメンバーアカウント"""

    __tablename__ = "web_accounts"

    id: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        primary_key=True, autoincrement=True
    )
    email: sqlalchemy.orm.Mapped[str] = sqlalchemy.orm.mapped_column(
        sqlalchemy.String(50), unique=True, index=True, nullable=False
    )
    member_id: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        sqlalchemy.ForeignKey("members.id"), index=True, nullable=False
    )
    icon: sqlalchemy.orm.Mapped[str] = sqlalchemy.orm.mapped_column(
        sqlalchemy.String(8), nullable=False
    )

    # Relationships
    member: sqlalchemy.orm.Mapped["Member"] = sqlalchemy.orm.relationship(
        back_populates="web_accounts"
    )
    histories: sqlalchemy.orm.Mapped[list["LessonHistory"]] = (
        sqlalchemy.orm.relationship(back_populates="web_account")
    )
    history_updates: sqlalchemy.orm.Mapped[list["WebAccountHistoryUpdate"]] = (
        sqlalchemy.orm.relationship(back_populates="web_account")
    )


class Program(Base):
    """プログラム"""

    __tablename__ = "programs"

    id: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        primary_key=True, autoincrement=True
    )
    name: sqlalchemy.orm.Mapped[str] = sqlalchemy.orm.mapped_column(
        sqlalchemy.String(12), unique=True, index=True, nullable=False
    )
    background_color: sqlalchemy.orm.Mapped[typing.Optional[str]] = (
        sqlalchemy.orm.mapped_column(sqlalchemy.String(20), nullable=True)
    )
    text_color: sqlalchemy.orm.Mapped[typing.Optional[str]] = (
        sqlalchemy.orm.mapped_column(sqlalchemy.String(20), nullable=True)
    )

    # Relationships
    lessons: sqlalchemy.orm.Mapped[list["Lesson"]] = sqlalchemy.orm.relationship(
        back_populates="program"
    )


class Lesson(Base):
    """レッスン"""

    __tablename__ = "lessons"

    sid: sqlalchemy.orm.Mapped[str] = sqlalchemy.orm.mapped_column(
        sqlalchemy.String(160), primary_key=True
    )
    store_id: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        index=True, nullable=False
    )
    store_name: sqlalchemy.orm.Mapped[str] = sqlalchemy.orm.mapped_column(
        sqlalchemy.String(20), nullable=False
    )
    instructor_id_1: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        nullable=False
    )
    instructor_name_1: sqlalchemy.orm.Mapped[str] = sqlalchemy.orm.mapped_column(
        sqlalchemy.String(20), nullable=False
    )
    instructor_id_2: sqlalchemy.orm.Mapped[typing.Optional[int]] = (
        sqlalchemy.orm.mapped_column(nullable=True)
    )
    instructor_name_2: sqlalchemy.orm.Mapped[typing.Optional[str]] = (
        sqlalchemy.orm.mapped_column(sqlalchemy.String(20), nullable=True)
    )
    start_at: sqlalchemy.orm.Mapped[datetime.datetime] = sqlalchemy.orm.mapped_column(
        index=True, nullable=False
    )
    end_at: sqlalchemy.orm.Mapped[datetime.datetime] = sqlalchemy.orm.mapped_column(
        nullable=False
    )
    program_id: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        sqlalchemy.ForeignKey("programs.id"), index=True, nullable=False
    )
    updated_at: sqlalchemy.orm.Mapped[datetime.datetime] = sqlalchemy.orm.mapped_column(
        nullable=False,
        server_default=sqlalchemy.func.now(),
        onupdate=sqlalchemy.func.now(),
    )

    # Relationships
    program: sqlalchemy.orm.Mapped["Program"] = sqlalchemy.orm.relationship(
        back_populates="lessons"
    )
    histories: sqlalchemy.orm.Mapped[list["LessonHistory"]] = (
        sqlalchemy.orm.relationship(back_populates="lesson")
    )


class LessonHistory(Base):
    """レッスン受講履歴"""

    __tablename__ = "lesson_histories"

    id: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        primary_key=True, autoincrement=True
    )
    web_account_id: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        sqlalchemy.ForeignKey("web_accounts.id"), index=True, nullable=False
    )
    lesson_sid: sqlalchemy.orm.Mapped[str] = sqlalchemy.orm.mapped_column(
        sqlalchemy.String(160),
        sqlalchemy.ForeignKey("lessons.sid"),
        index=True,
        nullable=False,
    )
    bike_number: sqlalchemy.orm.Mapped[str] = sqlalchemy.orm.mapped_column(
        sqlalchemy.String(20), nullable=False
    )
    ticket_type: sqlalchemy.orm.Mapped[typing.Optional[str]] = (
        sqlalchemy.orm.mapped_column(sqlalchemy.String(100), nullable=True)
    )
    is_absent: sqlalchemy.orm.Mapped[bool] = sqlalchemy.orm.mapped_column(
        nullable=False, default=False
    )

    # Relationships
    web_account: sqlalchemy.orm.Mapped["WebAccount"] = sqlalchemy.orm.relationship(
        back_populates="histories"
    )
    lesson: sqlalchemy.orm.Mapped["Lesson"] = sqlalchemy.orm.relationship(
        back_populates="histories"
    )


class WebAccountHistoryUpdate(Base):
    """Webメンバーアカウント受講履歴更新履歴"""

    __tablename__ = "web_account_history_updates"

    web_account_id: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        sqlalchemy.ForeignKey("web_accounts.id"),
        primary_key=True,
        index=True,
        nullable=False,
    )
    year: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        primary_key=True, nullable=False
    )
    month: sqlalchemy.orm.Mapped[int] = sqlalchemy.orm.mapped_column(
        primary_key=True, nullable=False
    )
    last_updated_time: sqlalchemy.orm.Mapped[datetime.datetime] = (
        sqlalchemy.orm.mapped_column(
            nullable=False,
            server_default=sqlalchemy.func.now(),
            onupdate=sqlalchemy.func.now(),
        )
    )

    # Relationships
    web_account: sqlalchemy.orm.Mapped["WebAccount"] = sqlalchemy.orm.relationship(
        back_populates="history_updates"
    )
```
